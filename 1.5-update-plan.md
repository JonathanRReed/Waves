## Product and Release Contract

Waves 1.5 is one consolidated reliability release. There will be no interim 1.4.5 release. It carries the confirmed patch fixes, complete repository cleanup, Wave Link coexistence, Stream Deck compatibility, hardened automation, and release infrastructure into one candidate.

The release must preserve these boundaries:

- Waves remains a native SwiftPM macOS app supporting macOS 14.2 or later.
- Release binaries remain universal `arm64` and `x86_64`.
- `ControlProtocol.version` remains `1`; no existing command or response shape may break.
- Persistence remains schema 1 and additive.
- No new production dependency may be added without separate approval.
- App Intents remain outside 1.5. Any later App Intents adapter must use the same AppStore intent boundary as the UI and existing automation.
- The Stream Deck plugin remains independently versioned and released from `/Users/jonathanreed/Downloads/waves-streamdeck`.
- Real Stream Deck and Wave Link compatibility is still a hard Waves 1.5 release gate.
- Audio is never recorded, transmitted, or used for telemetry.
