# Waves 1.5 Premium Onboarding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Waves' form-like first run and default DMG with a premium, truthful macOS install and onboarding journey that reaches the real mixer quickly and offers an optional, instantly dismissible live tutorial.

**Architecture:** Add versioned onboarding state and pure launch policy first, then two main-actor coordinators: one for required setup and one for optional mixer education. Keep `AppStore` as the only product mutation facade, attach tutorial chrome to real mixer controls, and extend the native release packager to build and verify an intentional Finder disk-image layout.

**Tech Stack:** Swift 6, SwiftUI, AppKit, Observation, Swift Testing, Core Graphics/AppKit image rendering, Bash 3.2-compatible release scripts, AppleScript through `/usr/bin/osascript`, Ruby release-infrastructure tests.

## Global Constraints

- Support macOS 14.2 and newer with no new production dependency.
- Keep version `1.5.0`, build `13`, schema `1`, bundle identity, protocol v1, Sparkle keys, signing policy, and audio-routing authority unchanged.
- Version `1` is the current required-setup, guided-tour, and What's New experience.
- Required setup contains only installation advice, local-processing context, Audio Capture permission, readiness repair, and the verified ready state.
- Required permission setup cannot be skipped or marked complete early. Closing it leaves setup incomplete.
- The optional tour has at most four moments and shows End Tour in every moment. Escape performs the same idempotent action.
- The tour acts only through real `AppStore` transactions and never plays sample audio, fabricates a route, or mutates unrelated preferences.
- Interactive tour moments have no manual Next bypass while their target exists. If the target disappears, the named recovery card retains Skip Step and End Tour.
- Existing completed users never repeat required setup. They may see one nonmodal What's New card and may replay setup or the tour manually.
- New users who complete the 1.5 setup do not immediately receive a redundant automatic What's New card, but can replay it from Help.
- Missing schema-1 keys decode additively. The raw 1.4.4 fixture remains the migration authority.
- All permission requests and System Settings launches are initiated by a visible user action.
- The DMG builder works in private scratch space, never changes the checkout, and verifies all staged inputs without following untrusted links.
- Do not stage, commit, tag, push, sign, notarize, publish, or deploy without explicit user authorization.
